## How to use them

Refresh the Skills Center and search for **GitHub**, or ask `phd-manager` to use a specific upstream skill. The bilingual project entries load the original instructions and relevant references. The original text remains in its source language; Chinese/English entry instructions do not pretend to be a full translation. New skill entries are available on your next turn; reload a client’s project/skill list if needed.

Only skill files are installed. Python libraries, local scientific software, remote accounts and paid services have not been installed or activated. Check the per-skill requirements before execution.

## Where the files live

- `skills/github-*/` contains the project’s bilingual entry and client metadata.
- `vendor/skills/<id>/upstream/` contains byte-preserved upstream files, separate from automatic client skill discovery.
- `vendor/skills/<id>/upstream-licenses/` retains the applicable repository license. Licenses originally inside a skill stay in place too.
- `skills/upstream-lock.json` records source, commit, requirements and every file checksum.

Run `npm run check` or `node scripts/check-upstream-skills.mjs` to verify the local copies without executing upstream code. Integrity checks detect missing, modified or unexpected files; they do not certify the upstream code or research quality.

Keep original vendor files unchanged. For a requested update, download the chosen new commit to a separate location, review changes and licenses, then replace the selected bundle and regenerate its checksums together. Updates are not automatic.

Research records still follow the project CLI and read-back rules. Generating a document or processing a log does not automatically increase paper progress. The integration does not grant uploads, publication, notifications, private-chat collection or paid computation.

## What was checked

Upstream paths, commit evidence, licenses, entry instructions and key scripts/dependencies were inspected. Vendored files were compared to the pinned downloads and hashed. Script-based scientific analyses and external services were not all executed; use the validation record for checks actually performed.

The first batch excludes the HF datasets workflow containing raw client-session collection examples and the K-Dense slides workflow with substantial additional service dependencies. The source inventories remain broader candidate lists; inclusion there is not installation.

The ML paper-writing bundle was also excluded: its venue templates include separate redistribution conditions and required source files were missing. The selected Orchestra ideation skill has no such template bundle.
