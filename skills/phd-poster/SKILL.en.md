# Academic posters

## Workflow

1. Confirm conference dimensions, orientation, language, template and format. If dimensions are unknown, prepare a layout draft without claiming print compliance.
2. Extract one central message and supporting evidence from the actual paper. Organize question, methods, findings and limitations with concise text and necessary sources.
3. Plan distant title recognition, readable body text and a clear reading order. Use real data or verified figures and label schematics.
4. Take authors, affiliations, funding, logos, contacts and QR destinations from supplied or verified material. Leave missing details unresolved instead of inventing contact information or publication links.
5. Use available layout/presentation tools for editable source and required output. Check physical dimensions, embedded fonts, image resolution, margins and print scaling; inspect the full page and details when rendering is possible.

## Deliverable

Deliver source, exports, dimensions and validation status. With missing tools, supply content and layout clearly marked as not yet exported for printing. Poster creation does not establish conference attendance or publication.

## Saving and workspace updates

Read the [local workflow](../phd-manager/references/local-workflow.en.md). Save artifacts to the requested location or repository `outputs/` without overwriting source material. Only when recording/updating is requested, use `node cli.mjs` to read current records and versions, validate required batches, save and read back; preserve `PHD_DATA_DIR`. Label AI plans with `origin: "ai"` and retain external provenance. Creating an artifact does not automatically increase paper progress or complete experiments.
