# Citation and reference audit

## Define the audit target

Read the selected manuscript and reference library while preserving originals and citation keys. Identify whether the task concerns formatting, bibliographic identity or support for scientific claims.
Keep the requested style and requirements; ask only for essential missing material. Reformatting the whole manuscript is not a prerequisite for an audit.

## Check citations in layers

1. Match in-text citations to bibliography entries and identify missing entries, uncited items, duplicate keys and duplicate works.
2. Check title, authors, year, venue, volume/pages and DOI/URL. Preprints and published papers are related versions; do not blend their metadata blindly.
3. For external verification prefer publisher pages, DOI landing pages, official bibliographic databases or author archives. Search snippets are leads.
4. Locate original passages, tables or results for important claims and classify support as sufficient, partial, contradictory or unverifiable.
5. Look for secondary citation, reviews used as primary evidence, population/condition mismatches and causal overstatement. Correct identity does not establish correct use.
6. When accessible, check retractions, corrections and updates and record the date. An unsuccessful search does not confirm that no retraction exists.
7. Correct verified low-risk metadata as requested. Explain changes to the cited work or scientific claim with sources; do not replace a source based on a similar title.
8. Recheck citation resolution after edits, preserving custom keys or updating every affected occurrence together.

## Deliver an audit table

List manuscript location, citation key, issue type, consulted source, verification level and proposed correction.
Separate confirmed errors, unresolved checks and style suggestions. A reference not found is not automatically fabricated.
When editing files, retain the original or a reviewable diff and state the number and scope of references actually checked.

## Access and format capabilities

- Without internet access, check local consistency and supplied sources; leave identity, retraction and current-metadata checks unresolved.
- Abstract-only access cannot verify full-text claims. Never invent DOI strings, pages or author names to fill gaps.
- Without Word-field or BibTeX tooling, deliver a correction table or supported text without claiming preservation of uninspected reference fields.
- Use [literature verification](../phd-literature/SKILL.en.md) when asked to update the ledger. An audit does not automatically advance paper progress.

## Workspace synchronization (only when requested)

Read the [local workflow](../phd-manager/references/local-workflow.en.md), locate the actual repository and project, and preserve the current PHD_DATA_DIR.
Discussion, translation, drafts and suggestions do not automatically change research state. Deliver requested files to the selected directory, or outputs/ when unspecified.
For requested saves, use the CLI to read the target and current version; preserve notes, relations and user-estimated percentages rather than editing the database directly.
Use user for user facts, import for external material and ai for AI plans/assessments, preserving provenance and actual verification scope.
Validate a batch before applying multiple changes and read back successful writes before reporting them as saved. Add no fields outside the contract.

## Imported upstream resources

When the task benefits from the original methods or bundled tools, use the [GitHub integration](../github-citation-management/SKILL.en.md) and read its complete upstream instructions. Check its requirements and scope; tool output does not replace the local record workflow.
