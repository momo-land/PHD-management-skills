# Research workflow routing

Read only the skill relevant to the request. These workflows do not require installing an upstream skill pack. Tool-dependent steps must check current capabilities; do not claim unavailable search, OCR, computation, compilation or rendering succeeded.

| Request | Skill |
| --- | --- |
| Topic selection, questions and candidate contributions | [phd-ideation](../../phd-ideation/SKILL.en.md) |
| Proposals, research plans and milestones | [phd-proposal](../../phd-proposal/SKILL.en.md) |
| Systematic-review search, screening and evidence matrices | [phd-systematic-review](../../phd-systematic-review/SKILL.en.md) |
| Close reading, method analysis and critical notes | [phd-paper-reading](../../phd-paper-reading/SKILL.en.md) |
| DOIs, references and claim support | [phd-citation-audit](../../phd-citation-audit/SKILL.en.md) |
| PDF text, tables and page-linked evidence | [phd-pdf](../../phd-pdf/SKILL.en.md) |
| Missingness, duplicates, units and leakage | [phd-data-quality](../../phd-data-quality/SKILL.en.md) |
| Analysis plans, effect sizes, uncertainty and computation | [phd-statistics](../../phd-statistics/SKILL.en.md) |
| Scientific data figures, captions and exports | [phd-visualization](../../phd-visualization/SKILL.en.md) |
| Paper reproduction, runs and discrepancy diagnosis | [phd-reproduce](../../phd-reproduce/SKILL.en.md) |
| Scientific code review, metrics and split verification | [phd-research-code](../../phd-research-code/SKILL.en.md) |
| Dictionaries, file organization, versions and backups | [phd-data-management](../../phd-data-management/SKILL.en.md) |
| LaTeX layout, bibliography and compilation repairs | [phd-latex](../../phd-latex/SKILL.en.md) |
| Academic translation and terminology consistency | [phd-academic-translation](../../phd-academic-translation/SKILL.en.md) |
| Real review comments, responses and revisions | [phd-rebuttal](../../phd-rebuttal/SKILL.en.md) |
| Submission checks, venue requirements and materials | [phd-submission](../../phd-submission/SKILL.en.md) |
| Lab meetings, conference talks and speaker notes | [phd-slides](../../phd-slides/SKILL.en.md) |
| Conference posters and print checks | [phd-poster](../../phd-poster/SKILL.en.md) |
| Thesis integration, chapters and consistency | [phd-thesis](../../phd-thesis/SKILL.en.md) |
| Defense statements, mock questions and evidence | [phd-defense](../../phd-defense/SKILL.en.md) |

Use the existing paper/experiment/literature skills for general drafting, experiment logging and reading records. An artifact request does not automatically authorize changing progress. When record updates are requested, preserve the current project/data binding and follow the [local workflow](local-workflow.en.md).
