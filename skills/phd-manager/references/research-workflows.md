# 科研工作流索引

按用户任务只读取相关技能，无需把第三方技能包全部安装。依赖工具的步骤先检查当前能力；没有实际检索、OCR、计算、编译或渲染时，不宣称已完成。

| 用户要做的事 | 技能 |
| --- | --- |
| 选题、研究问题、创新点候选 | [phd-ideation](../../phd-ideation/SKILL.md) |
| 开题报告、研究计划与里程碑 | [phd-proposal](../../phd-proposal/SKILL.md) |
| 系统综述检索、筛选与证据矩阵 | [phd-systematic-review](../../phd-systematic-review/SKILL.md) |
| 精读具体论文、方法拆解与批判笔记 | [phd-paper-reading](../../phd-paper-reading/SKILL.md) |
| DOI、参考文献与论点支撑核查 | [phd-citation-audit](../../phd-citation-audit/SKILL.md) |
| PDF 文本、表格与带页码证据提取 | [phd-pdf](../../phd-pdf/SKILL.md) |
| 数据缺失、重复、单位与泄漏检查 | [phd-data-quality](../../phd-data-quality/SKILL.md) |
| 统计方案、效应量、不确定性与实际分析 | [phd-statistics](../../phd-statistics/SKILL.md) |
| 论文数据图、图注与导出 | [phd-visualization](../../phd-visualization/SKILL.md) |
| 论文代码复现、运行与差异定位 | [phd-reproduce](../../phd-reproduce/SKILL.md) |
| 科研代码审查、指标与划分验证 | [phd-research-code](../../phd-research-code/SKILL.md) |
| 数据字典、资料组织、版本与备份 | [phd-data-management](../../phd-data-management/SKILL.md) |
| LaTeX 排版、参考文献与编译修复 | [phd-latex](../../phd-latex/SKILL.md) |
| 学术中英翻译与术语一致性 | [phd-academic-translation](../../phd-academic-translation/SKILL.md) |
| 真实审稿意见拆解、逐条回复与修订 | [phd-rebuttal](../../phd-rebuttal/SKILL.md) |
| 投稿前检查、目标期刊要求与材料 | [phd-submission](../../phd-submission/SKILL.md) |
| 组会、会议报告与讲稿 | [phd-slides](../../phd-slides/SKILL.md) |
| 会议海报与打印输出检查 | [phd-poster](../../phd-poster/SKILL.md) |
| 学位论文整合、章节结构与一致性 | [phd-thesis](../../phd-thesis/SKILL.md) |
| 答辩陈述、模拟提问与证据准备 | [phd-defense](../../phd-defense/SKILL.md) |

普通论文起草、实验登记和文献台账继续用已有论文/实验/文献技能。生成材料不自动改进度；用户要求同步时沿用当前课题和数据目录，按 [本地操作约定](local-workflow.md) 完成。
